# Endourology Pearls Portal (GitHub Pages)

1. Upload all contents of this folder (`index.html`, `.nojekyll`, and `pearls/`) to your GitHub repository (root or `docs/` folder).
2. In GitHub: **Settings → Pages → Deploy from a branch** (`main`, `/ (root)`).
3. Your live shareable portal will be available at `https://<your-username>.github.io/<repo-name>/` (and individual pearls can be shared via `?p=day34`, `?p=day33`, etc.).
